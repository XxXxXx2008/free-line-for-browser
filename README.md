# 橙线分屏

这是一个面向 Chromium 内核浏览器的自由分屏扩展源码仓库。

面向 Chromium 内核浏览器（包括支持 Chromium 扩展的小米浏览器桌面版）的
Manifest V3 扩展。一条橙色细线把当前扩展页分成两个实时网页区域：

bro可以自由分屏无限制哦，也就是说什么角度都可以的说

- 拖动橙线或中央小点，可自由移动分界位置。
- 默认提供两端点旋转：拖动任意一端，另一端保持固定。
- 也可切换为中心旋转；点击中央小点后，旋转按钮显示 5 秒。
- 在设置中可从预设色或系统调色盘选择橙线颜色。
- 可用滑杆将橙线粗细调整为 2–20 px。
- 可开启音频响应，让分割线两侧的镜像音乐条跟随系统或标签页音频起伏。
  音乐条使用 40 根高密度细条，当前总跨度 294px，单条宽度保持 5px。
- 中心点两侧提供镜像的后退、前进和刷新按钮，两组按钮分别控制两个网页。
- 返回按钮使用 `#80F0FF`，下一页按钮使用 `#FFA8F3`。
- 返回和下一页按钮可在设置中分别调色，箭头会自动使用适合背景的深色。
- 网页中的 `_blank`、`_top`、`_parent` 链接和表单会尽量留在当前分屏内。
- 网页区域使用旋转半平面遮罩和 iframe 反向旋转定位，不依赖
  `clip-path`，以降低 Edge/Chromium 播放视频时的合成崩溃风险。
- 检测到视频播放时自动切换为无旋转、无裁切合成的矩形分屏；暂停后
  自动恢复原来的自由角度。
- 两个旋转端点小球会限制水平活动范围，不能移出屏幕。
- 弹窗中的“当前网站”按钮可读取活动标签页网址并填入对应网页输入框。
- 拖动只改变 iframe 的裁剪路径，不重新加载两个页面。
- 在设置中更换网页、交换两侧位置或恢复默认分界。
- 网页输入会自动保存，并提供 4 个常用网址槽位。
- 分界位置、旋转模式、角度、颜色、粗细和网页地址会保存在浏览器本地。

## 本地安装

1. 打开浏览器的扩展管理页，并启用“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择 `orange-split-extension` 目录。
4. 点击工具栏中的“橙线分屏”图标，填写两个网页地址并开始分屏。

## 已知限制

网页是否能在分屏中显示，取决于该网站是否允许被其他页面嵌入。设置
`X-Frame-Options: DENY` 或 `Content-Security-Policy: frame-ancestors`
限制的网站会显示空白或错误页。扩展不会绕过网站安全策略；可通过设置面板
中的“在新标签打开”查看原网页。

扩展申请了 `<all_urls>` host 权限，以支持用户输入任意可嵌入网页；没有
后台脚本、远程脚本、统计、广告、账号或数据上传。

音频响应必须由用户点击按钮并在浏览器共享窗口中选择系统音频或标签页
音频。浏览器不允许扩展静默读取系统声音。共享提示可能会保留以便维持
音频轨道；扩展不会读取或上传共享画面，页面隐藏时会自动停止采集。

为让新窗口链接留在分屏中，扩展会在网页 frame 内运行
`frame-bridge.js`。该脚本只有收到当前分屏页的授权消息后才启用，用于
拦截新窗口链接、表单目标和处理前进/后退/刷新命令。网页脚本直接调用
`window.open()` 的情况仍可能由浏览器打开新标签页。
